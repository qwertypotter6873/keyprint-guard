글자가 매번 달라도 손가락의 생체 지문은 남습니다

키를 누르고 떼는 수 밀리초(ms)의 근육 습관이 어떻게 오타 수정과 타자 속도 변화를 이겨내고 나만의 64차원 생체 프로필로 만들어지는지 직접 조작하며 확인해 보세요.

STEP 01 · 손끝에서 생체 신호로

건반 피아노 롤 타임라인 & 오타·속도 보정 원리

예시 파형 로드됨
일반 홀드(Hold) 연타 롤오버(UD < 0, 앞 키 떼기 전 타건) 백스페이스 오타 격리·봉합
추출되는 17채널 특징 텐서 [1, 17, L]·행동 프로필 및 KeyPrintNet 구조 보기
① 물리 타이밍 (Ch 0~3)

현재·다음 키 누름 시간(H_curr, H_next), 키 간격(DD), 비행 시간(UD)을 서브밀리초 단위로 포착합니다.

② 속도 불변·봉합 역학 (Ch 4~8)

문장 평균 대비 상대 비율(Rel_H, Rel_DD), 듀티비, 롤오버 크기와 함께 백스페이스 봉합점의 가속도(Local_Accel)를 0으로 리셋해 인위적 튀는 값을 차단합니다.

③ 키 위치·손가락 (Ch 9~15) + 누름 시간 유효 플래그 (Ch 16)

어떤 키에서 어떤 키로 이동했는지(행·열 좌표, 이동 거리, 같은 손·같은 손가락 여부)를 넣어 키별 누름 습관과 접근 속도를 학습합니다. 누름 시간을 알 수 없는 터치 키보드는 Hold_Valid = 0으로 표시해 같은 모델이 모바일 입력도 처리합니다.

④ 행동 프로필 (모델 밖 통계)

백스페이스 비율·한 번에 지우는 길이·오타 인지/재개 지연, Shift·CapsLock 사용 방식, 멈춤 리듬을 누적합니다. 관찰 횟수가 적은 특징은 자동으로 영향이 0에 가까워지고, 융합 가중치는 검증 데이터로 정합니다.

⑤ KeyPrintNet 인코더 2개 (각 600KB ONNX)

상대 위치 고조파 + 다중 스케일 잔차 SE-Conv1D + 6모드 DCT 스펙트럼 풀링으로 길이에 무관하게 64-D 단위 초구면 벡터로 압축합니다. 타자연습 문장은 17채널 인코더를, 비밀번호는 사람마다 내용이 달라 학습에 없던 문자열이므로 키 정보를 보지 않는 9채널(Ch 0~8) 인코더를 씁니다.

STEP 02 · 프로필은 어떻게 만들어지는가

서로 다른 문장들이 하나의 '대표 지문(Centroid)'으로 수렴하는 과정

분석할 프로필 선택

매번 전혀 다른 글자의 문장을 쳐도 64-D 임베딩 바코드를 나란히 세워보면 개인 고유의 불변 차원(세로 강조 열)이 반복해서 나타납니다. 여러 문장을 누적 평균·정규화(L2 Centroid)하면 글자 배열 때문에 생긴 일시적 노이즈는 상쇄되고 선명한 대표 프로필만 남습니다.

프로필 수렴 안정도 — 누적 샘플 수에 따른 중심 수렴률
문장 간 지문 일관성 — 서로 다른 문장 간 평균 유사도
평균 홀드 습관 — 키를 누르고 있는 물리 시간
연타 롤오버 빈도 — 앞 키 떼기 전 다음 키 중첩 비율
STEP 03 · 왜 다른 문장을 쳐도 사람이 구별되는가

실시간 참가자 64차원 초구면 생체 지문 지도 (2D 주성분 투영)

작은 점(○)은 각 참가자가 서로 다른 문장을 쳤을 때의 개별 벡터이고, 큰 원(●)은 완성된 대표 프로필 중심점(Centroid)입니다. 동시 접속 방에 새 참가자가 등록되거나 새 문장을 치면(★) 지도 위에 실시간으로 반영됩니다.
